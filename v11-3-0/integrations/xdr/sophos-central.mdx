> Sophos Central provides secure APIs to retrieve event and alert data. UTMStack can utilize these APIs to centralize monitoring and enhance your security visibility

## Generate API Credentials in Sophos Central

### 1. Navigate to General Settings -> API Credentials Management in Sophos Central Admin.

<img
  height="200"
  src="/assets/38a018b0-b9f8-5cc9-b68e-5586046a445c"
  alt="Sophos"
/>

### 2. Create a New Credential

    * Click Add Credential (usually found at the top-right).
    * Provide Name and Description.
    * Select the appropriate Role.
    * Click Add.

<img
  height="200"
  src="/assets/8349b2f0-5618-568c-834e-db4b0c0bfc2f"
  alt="Sophos"
/>

### 3. Copy the Client ID and Client Secret and store them securely

<Note>
    The Client Secret is visible only once; ensure you save it somewhere safe.
</Note>

<img
  height="200"
  src="/assets/698b67a4-2486-5637-82ce-88edd4dd4717"
  alt="Sophos"
/>

* Click *Add tenant*
