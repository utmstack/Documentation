UTMStack v12 collects Kaspersky Security Center events through the **UTMStack Forwarder**, which the web interface calls the **Collector**. You enable the Kaspersky integration on a Collector, then turn on SIEM export in Kaspersky Security Center. Nothing is installed on your endpoints.

## Connection details

| Setting | Value |
|---|---|
| Card on the Integrations page | **Kaspersky** (category Antivirus) |
| Data type | `antivirus-kaspersky` |
| Default ports on the Collector | 7004/UDP; 7004/TCP (also used for TLS) |
| Included in UTMStack | A parsing filter and 19 detection rules |

## Before you begin

- A Collector must be installed and online. If you do not have one, see **UTMStack Forwarder**. One Collector can serve all your integrations.
- The Kaspersky Security Center server must reach the Collector host on the port you choose. Open it on the Collector host and on any firewall in between.
- You need the `integrations.write` permission to enable the integration from the web interface.

## Step 1: Enable the integration on a Collector

<Steps>
  <Step title="Open the integration">
    In UTMStack, go to **Configure > Integrations** and open the **Kaspersky** card.
  </Step>
  <Step title="Choose the Collector, protocol and port">
    Under **Enable this integration remotely**, select the **Collector**, the **Protocol** (**UDP**, **TCP** or **TLS**) and the **Port**. The port fills in with the default for the protocol.
  </Step>
  <Step title="Enable it">
    Click **Enable integration**. The panel then shows, for example, `Currently: enabled · udp · port 7004`.
  </Step>
</Steps>

To do the same on the Collector host instead, run:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder enable-integration antivirus-kaspersky 7004 udp
```

To use TLS, load a certificate on the Collector first. See **UTMStack Forwarder**.

## Step 2: Turn on SIEM export in Kaspersky Security Center

<Steps>
  <Step title="Open the integration settings">
    In the Kaspersky Security Center sidebar, open **Console settings** and click **Integration**.
  </Step>
  <Step title="Open the SIEM settings">
    Under **Integration**, select **SIEM** and click the **Settings** link.
  </Step>
  <Step title="Configure the export">
    Enable export and set Kaspersky to send events in **Splunk (CEF)** format to the Collector host on port 7004 (UDP).
  </Step>
</Steps>

## Step 3: Check that logs arrive

- In the **Kaspersky** drawer, click **View logs**. Log Explorer opens with the `antivirus-kaspersky` data type for the last 24 hours.
- Within about 10 minutes, the Kaspersky Security Center server appears on the **Data Sources** page under **Direct**.
- **Rules** and **Filters** in the same drawer open the detection rules and the parsing filter for this data type.

## Stop collecting

In the **Kaspersky** card, select the same Collector and click **Disable integration**, or run on the Collector host:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder disable-integration antivirus-kaspersky udp
```
