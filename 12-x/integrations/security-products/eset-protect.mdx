UTMStack v12 collects ESET PROTECT detections and events through the **UTMStack Forwarder**, which the web interface calls the **Collector**. You enable the ESET integration on a Collector, then turn on syslog export in the ESET PROTECT console. Nothing is installed on your endpoints.

## Connection details

| Setting | Value |
|---|---|
| Card on the Integrations page | **Eset** (category Antivirus) |
| Data type | `antivirus-esmc-eset` |
| Default ports on the Collector | 7003/UDP; 7003/TCP (also used for TLS) |
| Included in UTMStack | A parsing filter and 14 detection rules |

## Before you begin

- A Collector must be installed and online. If you do not have one, see **UTMStack Forwarder**. One Collector can serve all your integrations.
- The ESET PROTECT server must reach the Collector host on the port you choose. Open it on the Collector host and on any firewall in between.
- You need the `integrations.write` permission to enable the integration from the web interface.

## Step 1: Enable the integration on a Collector

<Steps>
  <Step title="Open the integration">
    In UTMStack, go to **Configure > Integrations** and open the **Eset** card.
  </Step>
  <Step title="Choose the Collector, protocol and port">
    Under **Enable this integration remotely**, select the **Collector**, the **Protocol** (**UDP**, **TCP** or **TLS**) and the **Port**. The port fills in with the default for the protocol.
  </Step>
  <Step title="Enable it">
    Click **Enable integration**. The panel then shows, for example, `Currently: enabled · udp · port 7003`.
  </Step>
</Steps>

To do the same on the Collector host instead, run:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder enable-integration antivirus-esmc-eset 7003 udp
```

To use TLS, load a certificate on the Collector first. See **UTMStack Forwarder**.

## Step 2: Turn on syslog export in ESET PROTECT

<Steps>
  <Step title="Open the More menu">
    In the ESET PROTECT console sidebar, click **More**.
  </Step>
  <Step title="Open Server settings">
    Under **More**, open **Server settings**.
  </Step>
  <Step title="Expand Advanced settings">
    Click **Advanced settings** to show all options.
  </Step>
  <Step title="Configure the syslog server">
    Scroll to **Syslog server**, enable **Export logs to Syslog**, and set the destination to the Collector host on port 7003 (UDP).
  </Step>
</Steps>

<Note>

The UTMStack v12 parsing filter for ESET reads ESET's JSON event export. If the console lets you choose the format of exported logs, choose JSON.

</Note>

## Step 3: Check that logs arrive

- In the **Eset** drawer, click **View logs**. Log Explorer opens with the `antivirus-esmc-eset` data type for the last 24 hours.
- Within about 10 minutes, the ESET PROTECT server appears on the **Data Sources** page under **Direct**.
- **Rules** and **Filters** in the same drawer open the detection rules and the parsing filter for this data type.

## Stop collecting

In the **Eset** card, select the same Collector and click **Disable integration**, or run on the Collector host:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder disable-integration antivirus-esmc-eset udp
```
