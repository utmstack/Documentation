UTMStack v12 collects IBM AIX logs through the **UTMStack Forwarder**, which the web interface calls the **Collector**. You enable the AIX integration on a Collector, then configure the AIX syslog service to send its logs to that Collector. Nothing is installed on the AIX system.

## Connection details

| Setting | Value |
|---|---|
| Card on the Integrations page | **Aix** (category Operating System) |
| Data type | `ibm-aix` |
| Default ports on the Collector | 7016/UDP; 7016/TCP (also used for TLS) |
| Included in UTMStack | A parsing filter and 10 detection rules |

## Before you begin

- A Collector must be installed and online. If you do not have one, see **UTMStack Forwarder**. One Collector can serve all your integrations.
- The AIX system must reach the Collector host on the port you choose. Open it on the Collector host and on any firewall in between.
- You need the `integrations.write` permission to enable the integration from the web interface.

## Step 1: Enable the integration on a Collector

<Steps>
  <Step title="Open the integration">
    In UTMStack, go to **Configure > Integrations** and open the **Aix** card.
  </Step>
  <Step title="Choose the Collector, protocol and port">
    Under **Enable this integration remotely**, select the **Collector**, the **Protocol** (**UDP**, **TCP** or **TLS**) and the **Port**. The port fills in with the default for the protocol.
  </Step>
  <Step title="Enable it">
    Click **Enable integration**. The panel then shows, for example, `Currently: enabled · udp · port 7016`.
  </Step>
</Steps>

To do the same on the Collector host instead, run:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder enable-integration ibm-aix 7016 udp
```

To use TLS, load a certificate on the Collector first. See **UTMStack Forwarder**.

## Step 2: Configure AIX to forward logs

On your AIX system, configure the syslog service to send its logs to the Collector host on port 7016. The exact syntax differs between AIX versions; see IBM's documentation for your version.

## Step 3: Check that logs arrive

- In the **Aix** drawer, click **View logs**. Log Explorer opens with the `ibm-aix` data type for the last 24 hours.
- Within about 10 minutes, the AIX system appears on the **Data Sources** page under **Direct**.
- **Rules** and **Filters** in the same drawer open the detection rules and the parsing filter for this data type.

## Stop collecting

In the **Aix** card, select the same Collector and click **Disable integration**, or run on the Collector host:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder disable-integration ibm-aix udp
```
