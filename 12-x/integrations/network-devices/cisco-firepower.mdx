UTMStack v12 collects Cisco Firepower logs through the **UTMStack Forwarder**, which the web interface calls the **Collector**. You enable the Cisco Firepower integration on a Collector, then configure Firepower Management Center (FMC) to send syslog to that Collector. Nothing is installed on your Firepower devices.

## Connection details

| Setting | Value |
|---|---|
| Card on the Integrations page | **Fire Power** (category Firewall) |
| Data type | `firewall-cisco-firepower` |
| Default ports on the Collector | 514/UDP; 1470/TCP (also used for TLS) |
| Included in UTMStack | A parsing filter and 5 detection rules |

## Before you begin

- A Collector must be installed and online. If you do not have one, see **UTMStack Forwarder**. One Collector can serve all your integrations.
- Your Firepower devices must reach the Collector host on the port you choose. Open it on the Collector host and on any firewall in between.
- You need the `integrations.write` permission to enable the integration from the web interface.

## Step 1: Enable the integration on a Collector

<Steps>
  <Step title="Open the integration">
    In UTMStack, go to **Configure > Integrations** and open the **Fire Power** card.
  </Step>
  <Step title="Choose the Collector, protocol and port">
    Under **Enable this integration remotely**, select the **Collector**, the **Protocol** (**UDP**, **TCP** or **TLS**) and the **Port**. The port fills in with the default for the protocol.
  </Step>
  <Step title="Enable it">
    Click **Enable integration**. The panel then shows, for example, `Currently: enabled · udp · port 514`.
  </Step>
</Steps>

To do the same on the Collector host instead, run:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder enable-integration firewall-cisco-firepower 514 udp
```

To use TLS, load a certificate on the Collector first. See **UTMStack Forwarder**.

## Step 2: Configure Firepower to forward logs

<Steps>
  <Step title="Open the platform settings">
    In Firepower Management Center (FMC), go to **Devices → Platform Settings**.
  </Step>
  <Step title="Add the Collector as a syslog server">
    Edit or create a policy and navigate to **Syslog → Syslog Servers**. Add the Collector IP with port 514 (UDP).
  </Step>
  <Step title="Deploy">
    Assign the policy to your devices and deploy.
  </Step>
</Steps>

If you enabled the integration with TCP or TLS, use port 1470 and the matching protocol in the syslog server entry.

## Step 3: Check that logs arrive

- In the **Fire Power** drawer, click **View logs**. Log Explorer opens with the `firewall-cisco-firepower` data type for the last 24 hours.
- Within about 10 minutes, each sending device appears on the **Data Sources** page under **Direct**.
- **Rules** and **Filters** in the same drawer open the detection rules and the parsing filter for this data type.

## Stop collecting

In the **Fire Power** card, select the same Collector and click **Disable integration**, or run on the Collector host:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder disable-integration firewall-cisco-firepower udp
```
