UTMStack v12 collects MikroTik RouterOS logs through the **UTMStack Forwarder**, which the web interface calls the **Collector**. You enable the MikroTik integration on a Collector, then add a remote logging action on the router that points at that Collector. Nothing is installed on the router.

## Connection details

| Setting | Value |
|---|---|
| Card on the Integrations page | **Mikrotik** (category Firewall) |
| Data type | `firewall-mikrotik` |
| Default ports on the Collector | 7007/UDP; 7007/TCP (also used for TLS) |
| Included in UTMStack | A parsing filter and 6 detection rules |

## Before you begin

- A Collector must be installed and online. If you do not have one, see **UTMStack Forwarder**. One Collector can serve all your integrations.
- The router must reach the Collector host on the port you choose. Open it on the Collector host and on any firewall in between.
- You need the `integrations.write` permission to enable the integration from the web interface.

## Step 1: Enable the integration on a Collector

<Steps>
  <Step title="Open the integration">
    In UTMStack, go to **Configure > Integrations** and open the **Mikrotik** card.
  </Step>
  <Step title="Choose the Collector, protocol and port">
    Under **Enable this integration remotely**, select the **Collector**, the **Protocol** (**UDP**, **TCP** or **TLS**) and the **Port**. The port fills in with the default for the protocol.
  </Step>
  <Step title="Enable it">
    Click **Enable integration**. The panel then shows, for example, `Currently: enabled · udp · port 7007`.
  </Step>
</Steps>

To do the same on the Collector host instead, run:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder enable-integration firewall-mikrotik 7007 udp
```

To use TLS, load a certificate on the Collector first. See **UTMStack Forwarder**.

## Step 2: Configure MikroTik to forward logs

On the MikroTik router, create a remote logging action pointing at the Collector host on port 7007 and attach it to the log topics you need. Run the following from the RouterOS CLI (Terminal in Winbox). Replace `<collector-ip>` with the address of the Collector host.

```text
/system logging action
add name=utmstack target=remote remote=<collector-ip> remote-port=7007 \
    bsd-syslog=yes syslog-facility=local0 syslog-severity=auto

/system logging
add action=utmstack topics=account,error,info,warning
```

You can also do this in Winbox: **System → Logging**, then on the **Actions** tab add a Remote action, and on the **Rules** tab add rules that use the new action.

<Note>

The setup guide in UTMStack fills in your UTMStack server's address in this step. Keep it only if the Collector runs on the UTMStack server; otherwise use the address of the Collector host.

</Note>

## Step 3: Check that logs arrive

- In the **Mikrotik** drawer, click **View logs**. Log Explorer opens with the `firewall-mikrotik` data type for the last 24 hours.
- Within about 10 minutes, the router appears on the **Data Sources** page under **Direct**.
- **Rules** and **Filters** in the same drawer open the detection rules and the parsing filter for this data type.

## Stop collecting

In the **Mikrotik** card, select the same Collector and click **Disable integration**, or run on the Collector host:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder disable-integration firewall-mikrotik udp
```
