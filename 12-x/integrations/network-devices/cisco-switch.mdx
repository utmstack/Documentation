UTMStack v12 collects Cisco switch logs through the **UTMStack Forwarder**, which the web interface calls the **Collector**. You enable the Cisco Switch integration on a Collector, then point the switch's syslog at that Collector. Nothing is installed on the switch.

## Connection details

| Setting | Value |
|---|---|
| Card on the Integrations page | **Cisco Switch** (category Network) |
| Data type | `cisco-switch` |
| Default ports on the Collector | 514/UDP; 1470/TCP (also used for TLS) |
| Included in UTMStack | A parsing filter and 3 detection rules |

## Before you begin

- A Collector must be installed and online. If you do not have one, see **UTMStack Forwarder**. One Collector can serve all your integrations.
- The switch must reach the Collector host on the port you choose. Open it on the Collector host and on any firewall in between.
- You need the `integrations.write` permission to enable the integration from the web interface.

## Step 1: Enable the integration on a Collector

<Steps>
  <Step title="Open the integration">
    In UTMStack, go to **Configure > Integrations** and open the **Cisco Switch** card.
  </Step>
  <Step title="Choose the Collector, protocol and port">
    Under **Enable this integration remotely**, select the **Collector**, the **Protocol** (**UDP**, **TCP** or **TLS**) and the **Port**. The port fills in with the default for the protocol.
  </Step>
  <Step title="Enable it">
    Click **Enable integration**. The panel then shows, for example, `Currently: enabled · udp · port 514`.
  </Step>
</Steps>

To do the same on the Collector host instead, run:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder enable-integration cisco-switch 514 udp
```

To use TLS, load a certificate on the Collector first. See **UTMStack Forwarder**.

## Step 2: Configure the switch to forward logs

On your Cisco switch, enable syslog and point it at the Collector host on port 514. From privileged EXEC mode, enter configuration mode (`configure terminal`), then run these commands. Replace `<collector-ip>` with the address of the Collector host.

```text
logging on
logging host <collector-ip>
logging trap informational
```

If you enabled the integration with TCP or TLS, configure the switch to send to port 1470 over that protocol instead. See Cisco's documentation for the syntax on your IOS version.

## Step 3: Check that logs arrive

- In the **Cisco Switch** drawer, click **View logs**. Log Explorer opens with the `cisco-switch` data type for the last 24 hours.
- Within about 10 minutes, the switch appears on the **Data Sources** page under **Direct**.
- **Rules** and **Filters** in the same drawer open the detection rules and the parsing filter for this data type.

## Stop collecting

In the **Cisco Switch** card, select the same Collector and click **Disable integration**, or run on the Collector host:

```bash
sudo /opt/utmstack-forwarder/utmstack_forwarder disable-integration cisco-switch udp
```
