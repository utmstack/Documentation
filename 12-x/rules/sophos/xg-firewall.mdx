Detection rules for **Sophos Firewall (XG)** data sources. Each rule includes its MITRE ATT&CK mapping, impact rating, and a description of what it detects. These rules analyze events with the data type `firewall-sophos-xg`, which the **Sophos Firewall (XG)** integration sends.

## Rule Example

Below is an example of a rule definition for **Probable Sophos denial of service (DoS) attack** ([view in repository](https://github.com/utmstack/UTMStack/blob/v12/definitions/rules/sophos/sophos_xg_firewall/sophos_denial_of_service.yaml)):

```yaml
# Sophos source-contract review; thresholds and impact ratings preserved.
dataTypes:
- firewall-sophos-xg
name: Probable Sophos denial of service (DoS) attack
impact:
  confidentiality: 3
  integrity: 3
  availability: 3
category: Impact
technique: T1499 - Endpoint Denial of Service
adversary: origin
references:
- https://docs.sophos.com/nsg/sophos-firewall/20.0/syslog/index.html
- https://attack.mitre.org/tactics/TA0040
- https://attack.mitre.org/techniques/T1499/
description: A Denial of Service (DoS) attack is an attempt to make a machine or network resource unavailable to
  the intended users. One common method of attack involves saturating the target machine with external communications
  requests so that it cannot respond to legitimate traffic or the machine responds so slowly that it is essentially
  useless.
where: equals("log.type","Firewall") && equalsIgnoreCase("log.component","DoS attacks") && equalsIgnoreCase("log.subType","DoS")
groupBy:
- lastEvent.dataSource
- lastEvent.log.sophosScope
- adversary.ip
- target.ip

```

## Rule Details

### Probable Sophos denial of service (DoS) attack

A Denial of Service (DoS) attack is an attempt to make a machine or network resource unavailable to the intended users. One common method of attack involves saturating the target machine with external communications requests so that it cannot respond to legitimate traffic or the machine responds so slowly that it is essentially useless.

- **Category:** Impact
- **Technique:** T1499 - Endpoint Denial of Service
- **Impact:** C:3 / I:3 / A:3
- **Rule file:** [sophos_denial_of_service.yaml](https://github.com/utmstack/UTMStack/blob/v12/definitions/rules/sophos/sophos_xg_firewall/sophos_denial_of_service.yaml)

### Probable Sophos ip spoofing attack

IP spoofing is the creation of Internet Protocol (IP) packets which have a modified source address in order to either hide the identity of the sender, to impersonate another computer system, or both. It is a technique often used by bad actors to invoke DDoS attacks against a target device or the surrounding infrastructure.

- **Category:** Impact
- **Technique:** T1499 - Endpoint Denial of Service
- **Impact:** C:3 / I:3 / A:3
- **Rule file:** [sophos_ip_spoofing_attack.yaml](https://github.com/utmstack/UTMStack/blob/v12/definitions/rules/sophos/sophos_xg_firewall/sophos_ip_spoofing_attack.yaml)

### Repeated Sophos IPS Priority 1 or 2 Detections

- **Category:** Intrusion Detection
- **Technique:** T1190 - Exploit Public-Facing Application
