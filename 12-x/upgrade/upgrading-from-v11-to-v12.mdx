An upgrade package from UTMStack v11 to UTMStack v12 is in progress. When it is released, it will give you a seamless transition from v11 to v12, with no data loss.

## What to do today

There is no upgrade package yet. Install UTMStack v12 only if you are starting from scratch.

| Your situation | What to do |
|---|---|
| You are starting from scratch | Install UTMStack v12. See **Install UTMStack**. |
| You run UTMStack v11 | Keep using v11 and wait for the upgrade package. |

## Protect your v11 server until then

<Warning>

**Do not run the v12 installer on your v11 server.** It does not upgrade v11.

</Warning>

<Warning>

**Do not download installers for your v11 server from the `releases/latest` link.** Since v12.0.2 was published, `https://github.com/utmstack/UTMStack/releases/latest/download/installer` gives the v12 installer. The same applies to the recovery script of the v11 "Installer Update Guide", which uses that link. Update your v11 server only with v11 installers.

</Warning>
