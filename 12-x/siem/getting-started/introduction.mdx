UTMStack 12 is the newest major version of UTMStack, a unified threat management platform. This page explains what UTMStack does, which editions exist, and what is new in version 12.

## What UTMStack does

UTMStack is an open-source platform that combines **SIEM** (Security Information and Event Management: collecting, storing and searching logs) and **XDR** (Extended Detection and Response: detecting threats across many sources and acting on them). It correlates log data, threat intelligence and malware activity patterns from many sources in real time, so that you can find and stop complex threats that use stealthy techniques.

Correlation happens while logs are being processed, before they are stored. This reduces the work the server has to do later and shortens the time between an event and an alert.

## Editions

UTMStack v12 comes in two editions. A licence can also add the multi-tenant option.

| Edition | How you get it | What it adds |
|---|---|---|
| Community | Free and open source. No licence file is needed. | The core platform: log collection and search, correlation rules, alerts, incidents, automated response, dashboards, threat intelligence, SOC-AI and the CMMC 2.0 and GDPR compliance frameworks. |
| Enterprise | A licence from UTMStack, installed in **Configure > Settings > License** | API keys, single sign-on (identity providers), white-label branding and all shipped compliance frameworks. |
| Multi-tenant option | Part of an Enterprise licence for managed service providers (MSSPs) | Tenants on one server, support access to tenants, and **Apply to all tenants**. |

A licence is issued for one server, identified by its instance ID. If a licence expires or cannot be verified, UTMStack falls back to Community. See **License and Editions** for the details.

## What's new in UTMStack v12

### The platform at a glance

Version 12 is a rebuild of most of the product. The main changes compared with v11:

- **New storage.** Logs, alerts and statistics are stored in ClickHouse instead of OpenSearch. Older data can move to cold storage (an S3-compatible bucket, Azure Blob Storage or a local or NFS folder) and stays searchable.
- **Rewritten backend and web interface.** The backend is written in Go and the web interface in React. The menus, pages and labels are different from v11.
- **One port for agents.** Agents and collectors reach the server on port 443 only. Ports 9000, 9001 and 50051 are no longer used.
- **Syslog and NetFlow move to the UTMStack Forwarder.** Network devices send their logs to the UTMStack Forwarder (shown as "Collector" in the product), a separate service you install on a Linux machine, instead of to the UTMStack server. See **UTMStack Forwarder**.
- **Real tenants.** On a multi-tenant licence, each tenant has its own users, settings, alerts, integrations, response flows and audit data. v11 data source groups no longer exist.
- **Two-step sign-in is per user.** Each user turns it on in their own profile. There is no longer a global switch.
- **Licensing.** API keys, single sign-on and white-label branding now need an Enterprise licence.
- **Operating systems.** The installer accepts Ubuntu, Debian and Red Hat Enterprise Linux.
- **Installation.** There is no ISO image for v12; install with the installer program. See **Install UTMStack**.

The release also contains many fixes. Among them: updates no longer wipe manual memory settings, correlation rules no longer disappear after updates, custom integrations receive data correctly, and the Windows install command works correctly.

### v12.0.1

This release improves installation and update reliability, especially on Debian and Ubuntu.

- Installation on Debian and Ubuntu completes more cleanly.
- Updates are less likely to fail when temporary files are stored in a different location.

### v12.0.2

This release improves sign-in reliability and corrects the AWS integration.

- The AWS integration now refers to CloudWatch instead of IAM User.
- A sign-in issue that could occur when no user name was entered is fixed.
