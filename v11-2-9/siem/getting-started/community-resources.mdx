## **Contributing**

We welcome contributions from the community! **UTMStack-specific plugins are Open Source**, and we encourage developers to submit improvements or new integrations.

1. **Bug Reports**: Open an issue on GitHub with logs and steps to reproduce.
2. **Feature Requests**: Use GitHub Discussions to propose new plugins or features.
3. **Pull Requests**: Submit code for UTMStack plugins or documentation improvements directly.
4. **Custom Rules**: Share your YAML detection rules in the Community Rules repository.
