### AWS Backup Deletion for Impact

Detects deletion of AWS Backup vaults, recovery points, or backup plans which could indicate an attacker attempting to prevent recovery after a destructive attack. Removing backups is a common precursor to ransomware or data destruction campaigns.

- **Category:** Impact
- **Technique:** T1490 - Inhibit System Recovery
- **Impact:** C:1 / I:3 / A:3
- **Rule file:** [aws_backup_deletion.yml](https://github.com/utmstack/UTMStack/blob/v11/rules/cloud/aws/aws_backup_deletion.yml)

- **Reference:** [https://attack.mitre.org/techniques/T1490/](https://attack.mitre.org/techniques/T1490/)
